# PBO Laravel - Latihan Lidya

## Deskripsi
Project ini merupakan latihan praktikum Pemrograman Berorientasi Objek (PBO) menggunakan framework Laravel.

Project ini menampilkan daftar buku dan daftar tugas mahasiswa beserta halaman detailnya.

## Fitur
- Menampilkan daftar buku.
- Menampilkan detail buku.
- Menampilkan daftar tugas mahasiswa.
- Menampilkan detail tugas berdasarkan ID.
- Menampilkan status tugas (Selesai dan Belum Selesai).

## Teknologi
- PHP
- Laravel
- Blade Template
- HTML

## Cara Menjalankan Project
1. Clone repository ini.
2. Buka folder project di VS Code.
3. Jalankan perintah:

   composer install

4. Jalankan server Laravel:

   php artisan serve

5. Buka browser dan akses:

   `http://127.0.0.1:8000`
